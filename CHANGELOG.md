# NOOBTOPIA changelog

## 2026-11-03

- **feat(deadweight): DEADWEIGHT's rules and its citizen policy now run here, emitted from the SAME PARENA source SHANKPIT compiles to C.** Founder: *"start porting the whole thing to NOOBTOPIA clone it down use PARENA build out any missing lua glue"*. The port is not a rewrite: `scripts/gen_deadweight.sh` emits `src/generated/deadweight_rules.lua` (105 cards, the kind triangle, every cost/power/credit, the packed fx engine, the match constants — 68 functions) and `src/generated/deadweight_policy.lua` (win rate, identity, the answer to a meta, card scoring, deck crafting) straight from `PARENA/stdlib/deadweight/{card_rules,citizen_policy}.prn`, which SHANKPIT emits to `dw_rules.c`/`dw_citizen_rules.c`. **The glue had to be built first, in PARENA:** the Lua target could not express `let` (the policy's binding vector fell through to the call branch: "unsupported expression form"), and `(do ...)`/`set!`/loops/`def`/`defstruct`/`match`/`case` silently emitted `M.do(1, 2)` — plausible-looking Lua that only an interpreter rejects. `let` now lowers to an immediately-invoked function (one expression, `local`s in source order, so a later binding reads an earlier one) and those statement forms refuse by name. Verified: `lua tests/deadweight_test.lua` — **287 checks, 0 failed**, every expected value hand-derived from the `.prn` rather than read back: hull 20 / energy 2 / credits 3 / four-card hands / 100 rounds / 105 cards, the base line's tier→cost 1/2/4, the triangle total and antisymmetric with Offense beating Operations and Defense beating Offense, a pass dealing nothing, legality by energy and credits, the policy's Laplace smoothing (0-0 is 500, 1-1 is 666, 0-4 is 166), identity/answer kinds, a 400-permille meta not counting as a meta, an unplayable card masked -1, ties with pass passing, slot 0/1/3/13 of a crafted deck, and every crafted id for every path and both ends of a record inside `numCards()`. `luac -p` accepts both generated modules; the existing `ambient_test.lua` and `walk_test.lua` still pass. NOT ported yet, named in `docs/DEADWEIGHT_PORT.md`: the **sequencer** (`SHANKPIT/packages/simulation/dw_match.c` — 32 effect channels, bankruptcy, 100-round draw), the **ladder** (challenges/records/meta), the **Roblox surface** (table, prompt, board GUI), and publishing the same schema WOTAN reads. Two real risks recorded there: Luau's numbers are doubles (32-bit-overflow rules would differ — the seed-mixer bug is precedent), and plain Lua 5.4 is not Luau.

## 2026-10-31

- **fix(ambient): `nextSeed` now matches the C host exactly, and the tests pin it.** `src/ambient.lua` carried the 1103515245 mixer, which needs ~61 bits while a Luau number holds 53 — so `Ambient.nextSeed` and SHANKPIT's `ambient_life_next_seed` returned different values above a seed near 2^31 and the two worlds talked over different lines. It is now MINSTD (`* 48271 mod 2^31-1`), identical to the C, with a negative seed clamping to 0. Verified: `tests/ambient_test.lua` pins the same four vectors `SHANKPIT/packages/simulation/ambient_life_test.c` pins (0, 42, 999999, 2147483646 → `2147435376`) and runs clean; `tests/walk_test.lua` still clean. NOT verified, named: plain Lua 5.4 has 64-bit integers, so a passing run here is *not* proof of Luau behaviour in general — only these four vectors are arithmetic-exact in both.

- **feat(wander): where a noob drifts, and when, is now PARENA's decision — and the Luau half runs for real.** `src/wander.lua` is the headless host: integer world units, a permille credit, no `Vector3`, no `wait`, no `game` — so `tests/walk_test.lua` can run it under a plain interpreter. The Roblox host (`src/noobtopia.lua`) now walks by it, replacing a `math.random() < 0.02` nudge on a single axis that could not be shared with anything; direction comes from the shared heading, magnitude from `arena_rules`'s own `stepSpeed`, so slippery physics still applies. `tests/walk_test.lua` asserts the same `PARENA/stdlib/noobtopia/walk_parity.txt` rows SHANKPIT's `make test-walk-rules` asserts, plus the properties a designer means by "it wanders": a startled noob frozen at 0 permille, a curious one pausing least and roaming furthest, a leash that holds over 3000 ticks, a leg that terminates, and the same seed walking the same path twice. Verified: `lua tests/walk_test.lua` — 13 parity vectors, 0 failed; `lua tests/ambient_test.lua` still clean. **A bug found by finally executing this repo:** the seed mixer in `src/ambient.lua` (`* 1103515245`) needs ~61 bits, and Luau numbers are doubles (exact to 2^53), so it silently diverges from the C above a seed near 2^31 — seed 2147483646 yields `2087949151` exactly, `2087949312` in double arithmetic. `wander.lua` therefore uses MINSTD (`* 48271 mod 2^31-1`); `ambient.lua`'s own mixer is left untouched and named in `../docs/THREE_WAY_MERGE.md` §3b, because changing it moves every existing ambient draw. NOT verified, named: **Roblox itself** — no Studio, no place file, no publishing; plain Lua 5.4 is not Luau (it has 64-bit integers where Roblox has doubles), so the test run proves the rules and the integration but never the `workspace` host.
