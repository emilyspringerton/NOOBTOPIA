# NOOBTOPIA changelog

## 2026-10-31

- **feat(wander): where a noob drifts, and when, is now PARENA's decision — and the Luau half runs for real.** `src/wander.lua` is the headless host: integer world units, a permille credit, no `Vector3`, no `wait`, no `game` — so `tests/walk_test.lua` can run it under a plain interpreter. The Roblox host (`src/noobtopia.lua`) now walks by it, replacing a `math.random() < 0.02` nudge on a single axis that could not be shared with anything; direction comes from the shared heading, magnitude from `arena_rules`'s own `stepSpeed`, so slippery physics still applies. `tests/walk_test.lua` asserts the same `PARENA/stdlib/noobtopia/walk_parity.txt` rows SHANKPIT's `make test-walk-rules` asserts, plus the properties a designer means by "it wanders": a startled noob frozen at 0 permille, a curious one pausing least and roaming furthest, a leash that holds over 3000 ticks, a leg that terminates, and the same seed walking the same path twice. Verified: `lua tests/walk_test.lua` — 13 parity vectors, 0 failed; `lua tests/ambient_test.lua` still clean. **A bug found by finally executing this repo:** the seed mixer in `src/ambient.lua` (`* 1103515245`) needs ~61 bits, and Luau numbers are doubles (exact to 2^53), so it silently diverges from the C above a seed near 2^31 — seed 2147483646 yields `2087949151` exactly, `2087949312` in double arithmetic. `wander.lua` therefore uses MINSTD (`* 48271 mod 2^31-1`); `ambient.lua`'s own mixer is left untouched and named in `../docs/THREE_WAY_MERGE.md` §3b, because changing it moves every existing ambient draw. NOT verified, named: **Roblox itself** — no Studio, no place file, no publishing; plain Lua 5.4 is not Luau (it has 64-bit integers where Roblox has doubles), so the test run proves the rules and the integration but never the `workspace` host.
